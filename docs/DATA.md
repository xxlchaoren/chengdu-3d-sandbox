# 数据与近似说明 · Data & Approximation

本沙盘不用真实 GIS 数据（那是"零外部请求"约束的代价），但所有**结构性量级**都取自可核实的公开资料。这份文档写清三件事：用了什么数、放在代码哪里、哪些地方是刻意近似。

## 一、坐标与尺度约定

| 项 | 值 | 出处 |
|---|---|---|
| 原点 | 天府广场 30.6577°N，104.0657°E | `src/geo/project.ts` |
| 单位 | **1 场景单位 = 100 m**（`UNIT_PER_KM = 10`，`unit(m) = m/100`） | `src/geo/project.ts` |
| 朝向 | 北 = −Z，方位角自正北顺时针 | 同上 |
| 垂直尺度 | **1:1，不做夸张** | `src/city/terrain.ts` |

> 反复出现的 bug 类型：`polar(distKm, bearingDeg)` 收的是**公里**并返回场景单位，而相机模块的 `distance` 已经是场景单位。跨模块传距离必须显式除以 `UNIT_PER_KM`。

河流：府河、锦江（南河）、锦江下游、沙河、江安河、毗河、金马河（岷江）、羊马河、潦河（第二绕城以北）、沱江支流（绛溪河）。**共同走向西北—东南**，府河与南河在合江亭汇成锦江后向南折，这是成都水系最重要的形态特征。

湖泊：兴隆湖、东安湖、北湖（青龙湖）、升仙湖、锦城湖、麓湖、三岔湖、鲁家滩（金马河）、天鹤湖（东部新区）、百花潭·浣花溪水面、二仙桥公园水系。

浣花溪公园、文化公园、望江楼公园、活水公园、新华公园、塔子山公园、离堆公园·杜甫草堂园林、百花潭公园、成都市植物园、三圣乡·花乡农居等 28 处，按实际方位落位。

## 五、时间与光照

成都位于东经 104.0657°，比东经 120° 基准**晚约 64 分钟**：`LONGITUDE_CORRECTION_H = (104.0657 - 120) / 15 ≈ −1.062 h`（`src/core/sky.ts`）。因此成都的日落常在北京时间 20:00 前后，沙盘开场定在 **20:12（蓝调时刻）**——太阳落到地平线下约 1°，天空余色未消而路灯、窗光、环路车流光河已全部点亮。

预设时刻：清晨 06:36 / 正午 13:06 / 黄昏 19:54 / 深夜 22:36。大气透视 `FogExp2` 基准密度 0.00038，雾/雨/雪天气在此基础上叠加。

> 参考事实：2025 年成都中心城区遥望雪山天数达 81 天，创历史新高。

## 六、刻意近似一览

| 项 | 做法 | 为什么 |
|---|---|---|
| 建筑单体 | 极坐标格网 + `urbanity()` 密度场生成，无真实轮廓 | 零外部请求；换到街区尺度已用 `fillBlocks()` 补附属体量 |
| 支路路网 | 只建环线/放射/主干格网 | 支路在沙盘视角下不可读，收益远低于几何开销 |
| 轨道线形 | 按线路走向与站点数近似，不用真实曲线 | 视觉上等价，且保证 7 号线是闭合环 |
| 湖泊命名 | 部分就近归并（如北湖与青龙湖） | 保留水面分布格局优先于名称精确 |
| 阴影 | 无 shadow map，用法线/AO 近似 | 千级实例下的帧率代价；夜景本来不依赖投影 |
| 地形 | 无 DEM，用解析山壳 | 需要的是"三面锁住平原"的可辨识度，不是等高线 |
